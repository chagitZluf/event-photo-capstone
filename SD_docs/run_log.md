# יומן הרצה ותיעוד התקנה

## 01 | סביבת העבודה
- מערכת הפעלה: Windows 10
- תיקיית הפרויקט: C:\חגית\Event Photo Capstone
- שפה: Node.js

## 02 | שלבי ההתקנה
1. פתחתי את תיקיית הפרויקט במחשב
2. הרצתי `npm install` להתקנת כל החבילות
3. הרצתי `npm start` להפעלת השרת

## 03 | תוצאות בדיקה

### GET /events
- סטטוס: עובד
- תוצאה: מחזיר רשימת אירועים מה-memory-store

### PUT /events/:id (עדכון כותרת)
- סטטוס: נקודת הקצה לא קיימת
- תוצאה: יש לממש אותה

## 04 | הצעות AI ומה עשיתי איתן

### הצעה 1 — הוספת נקודת קצה PUT (אושרה)
- סיבה: לא קיימת נקודת קצה לעדכון בקוד. PUT היא הדרך הסטנדרטית ב-REST לעדכון משאב.

### הצעה 2 — שימוש ב-PATCH במקום PUT (נדחתה)
- סיבה: PATCH מיועד לעדכון חלקי. בשלב זה PUT פשוטה יותר ומתאימה לרמת הפרויקט.
